Driller is a command-line HTTP load tester. Start with
[Getting started](/docs/getting-started) to install it and run a first test,
then keep [Benchmark syntax](/docs/syntax) and the
[CLI reference](/docs/cli-reference) at hand while writing plans.

Plans written for the original `drill` run unchanged;
[Migrating from drill](/docs/migrating-from-drill) has the details.
